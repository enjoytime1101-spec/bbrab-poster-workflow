# Changelog

## 3.0.0 — 2026-09-30

First public release of the standalone workflow asset pack, aligned with the local v3 prototype. Includes an offline brief compiler, aerospace evidence gates, reference fingerprints, four English prompt cards, a self-contained Skill, portable workflow specification, tests and static Playground.

Image generation, durable approval/review, billing and production deployment remain host responsibilities. This is not a release of the full local workbench.
