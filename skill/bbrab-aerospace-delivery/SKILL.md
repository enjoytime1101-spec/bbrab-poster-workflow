---

从已有企业档案读取品牌名、卫星或火箭领域、节日和已授权素材。缺少事实只收集一次；不让客户反复描述“高级感”。不推断企业型号、运载参数、成功次数或合作关系。

调用前读取 `/api/create/aerospace/capabilities`。PNG / MP4 未就绪时，仅交付可用的方案与 SVG，并说明实际状态。能力目录不能作为成功证据。

使用 [接口契约](references/api.md) 优先复用私有企业档案和产品素材，生成产品主视觉、品牌编辑版、横幅问候版三种完整排版。客户只筛选方案，不需要反复改提示词。首期品牌流程仅支持卫星／火箭＋中秋，必须提供已授权产品图；不把本地概念样片或模型生图说成平台已具备能力。

客户选定后提交该方案编号。重复提交复用原任务；网络超时先读取已有任务，不创建新的资料。客户无需选择模型或编写提示词。用户明确要求其他行业或自定义设计时，说明当前模板边界，保留原需求，不擅自转成航天海报。

仅 `completed` 且实际文件校验有效时称为完成。下载 PNG / MP4 并核对 SHA-256、品牌版 1920×1080（旧版 1280×720）、视频约 6 秒；至少查看一次实际成片以发现缺字、溢出与素材变形。排队、方案 JSON 和预览均不代表出片成功。失败保留原方案，最多三次人工触发尝试，不循环烧资源。

本工作流模板渲染不调用模型。只发送一次结构化企业资料，不在轮询中重发 SVG、图片或长提示词。私有素材不发往模型供应商；下载沿用账户鉴权，不把 token 放进 URL。选择与保存不授权对外发布。

Remotion 运行环境必须用实际渲染验收，并按团队实际规模核验许可条件。Skill 是操作指导；真正的排队、鉴权和文件校验由平台后端执行。

技术验收与客户采用分开：文件通过检查后仍为待客户选择；只在客户明确选择采用时记录 adopted。用户不采用时记录反馈，不自动循环重绘。企业档案版本必须随作品冻结；无权限素材不可引用。
