# Security

Do not put credentials, customer images or private operational data into public issues, examples or the Playground. The CLI is a local trusted-user tool, not a network service. A hosting application must enforce authentication, authorization, request limits and storage isolation.

Report vulnerabilities through this repository's private GitHub security reporting feature when available. If unavailable, open a minimal issue requesting a private reporting channel without exploit details or sensitive data. Only the latest release is maintained; no response-time commitment is made.
