# Contributing

Open a focused issue or pull request with the customer problem, changed behavior, limitations and relevant tests. Keep public documentation and interface text English; customer-supplied content may use any language. Use fictional fixtures and never commit credentials or customer materials.

Run the unittest suite, JavaScript syntax check and CLI example before proposing changes. Add regression tests for changed evidence or acceptance boundaries. Do not advertise image generation, model benchmarks or production integration without reproducible evidence. Keep the compiler standard-library-only unless a dependency has a concrete need and license review.
